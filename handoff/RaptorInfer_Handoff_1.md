# HANDOFF — Raptor 추론 + 공개 파이프라인 순위 혼합 노트북

작성: kim cheol hui | 날짜: 2026-10-05 | 브랜치: `feat/raptor-infer` (base: `feat/slot-infer`, `exp/007-raptor` merge)

## 1. 요약 (TL;DR)
- 추론이 exp007 Raptor 입력(`input: raptor_stack`)을 지원한다: test DICOM → `build_stack()`(학습 코퍼스와 비트 단위 동일) → 고르게 뽑은 2.5D 창.
  슬라이스(b0)·칸 이미지(DINO)·Raptor 세 입력 방식을 한 제출에서 순위 평균할 수 있다.
- `kaggle/build_public_blend.py`: 공개 0.943 노트북의 셀을 그대로 두고 끝에 셀 2개를 붙여
  우리 앙상블(별도 프로세스)을 라벨별 순위로 `w`만큼 섞는 노트북을 만든다. 우리 단계가 실패하면 공개 결과를 그대로 제출한다.
- 코드 데이터셋에 `run_submission.py`(= `kaggle/submission.py`)를 함께 넣는다 — 혼합 노트북이 이것을 실행한다.

## 2. 한 일과 결정 기록
| 항목 | 결정 | 이유 |
|------|------|------|
| 우리 앙상블 실행 | 공개 노트북 프로세스 밖(subprocess) | 공개 파이프라인의 패키지 버전·GPU 메모리와 섞지 않는다. 시작 전에 `torch.cuda.empty_cache()` |
| 실패 처리 | 우리 결과가 없거나 비유한값이면 공개 결과만 제출 | 혼합이 제출을 망치지 않게 |
| 실행 환경 | 공개 노트북 메타데이터의 `docker_image`·`machine_shape`를 그대로 | 공개 파이프라인이 고정한 환경 |
| 저작자 표기 | 노트북 첫 셀에 출처·저작자 명시 | 공개 코드를 그대로 쓰므로 |
| Raptor 묶음 | 볼륨 공유 대상에서 제외(자체 DICOM 읽기) | 스택 규칙(구간·밝기·자르기)이 다르다 |

## 3. 결과
- `ruff check`, `ruff format --check` 통과. `pytest -q` 128 passed, 2 skipped
- 새 테스트: Raptor 멤버 DICOM 추론, 세 입력 방식 동시 앙상블 = 각자 예측의 순위 평균, 혼합 노트북 생성(셀·메타데이터), 순위 혼합 계산, 우리 결과 없을 때 공개 결과 유지
- 혼합 노트북 시간 가드: 노트북 시작 후 8.3시간까지만 우리 단계를 돌리고(`subprocess.run(timeout=...)`, 경과 시간은 `psutil` 프로세스 시작 시각), 넘으면 공개 결과만 제출
- Kaggle 실행 `kimche12/rsna-knee-public-blend` v1: 공개 파이프라인 완료 → 우리 앙상블(exp006·002·003r) 0.7분, fallback 0 → 0.9 + 0.1 혼합 → 제출 `56851368` **Public LB 0.938** (공개 노트북 0.946보다 낮음 → 약한 모델(정답 58 0.83)을 10% 섞으면 손해, 채점 약 8.5시간)

- 2026-10-05: 가중치 데이터셋을 exp007 단독(`ensemble.yaml` exp007 1.0)으로 갱신. 정답 58에서 exp007 + 기존 앙상블 순위 평균은 0.904 → 최대 0.905(0.9:0.1)로 이득이 없어 단독으로 둠
  - 제출 `56856929`: exp007 단독 (`rsna-knee-submit` v7, 공개 test 3건 GPU 35.7초, fallback 0) — **Public LB 0.918** (이전 최고 0.857, 공개 원작자 단일 0.924)
  - 제출 `56857169`: 공개 파이프라인 0.8 + exp007 0.2 (`rsna-knee-public-blend` v2, 공개 노트북 셀은 v1과 동일, 우리 단계 0.5분) — **Public LB 0.943** (공개 노트북 0.946보다 낮음)
  - 정리: 공개 0.946에 LB 0.857 모델 10% → 0.938, LB 0.918 모델 20% → 0.943. 우리 모델이 공개 파이프라인보다 약한 동안은 섞으면 손해 → 단독 0.94 이상이 된 뒤 다시 혼합

- 2026-10-06: 3모델(exp007 + exp008-v2 + exp008-mean, 같은 비중 순위 평균) 가중치를 **새 데이터셋** `kimche12/rsna-knee-weights-r3`로 올림
