# Paper Review & Implementation Rules
- When reviewing a research paper in the `papers/` directory, analyze it with the following structure:
  1. **Core Contribution**: What is the main problem and novel approach?
  2. **Architecture**: Detailed breakdown of the neural network layers and data flow.
  3. **Loss Function & Metrics**: Exact formulas or loss types used for optimization.
  4. **TDD Implementation Plan**: How to break down this paper's architecture into modular, testable PyTorch code components.
