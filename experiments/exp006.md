# exp006 — 공개 상위 노트북의 DINO 레시피를 우리 코드로 재구현

## 배경
- 지금 최고: exp002 + exp003r 순위 평균 앙상블 **Public LB 0.847**. 목표 0.955.
- 공개 상위 노트북(0.94대)은 모두 "Speedy Raptors" 계열 앙상블이다. 그 안의 DINO 단계를 분석해 우리 exp004/005와 다른 점을 정리했다.

| 항목 | 공개 레시피 | exp004/005 |
|------|-------------|------------|
| 시야 | PixelSpacing 기준 무릎 중심 130 mm | 촬영 시야 전체 |
| 좌우 | 오른 무릎을 뒤집어 방향 통일 | 그대로 |
| 칸 | (단면 × fluid × 지방억제) 6칸, 지방억제는 SeriesDescription 정규식 | (단면 × CSV `Fat_Suppression`) 6칸 |
| 입력 | 칸마다 가운데 20–80% 구간 슬라이스 3장 = RGB 1장 (study당 6장) | 칸마다 16장 (study당 96장) |
| 특징 | CLS + patch 평균 | CLS |
| 집계 | 칸 6개 attention + 라벨별 칸 사전 가산점 | 슬라이스 96개 attention |
| 백본 lr | **8e-6**, 마지막 6블록 | 3e-5 / 1e-4(붕괴) |
| 학습 | 10 epoch, batch 8 study, 증강(회전 8°, 확대 8%, 이동 5%, 밝기 10%) | 4–6 epoch, batch 2 |

## 가설
공개 레시피대로 입력·헤드·학습률을 맞추면 DINOv2가 b0(exp002/003r, 정답 58 CV 0.78)보다 좋아지고,
b0와 성격이 달라 앙상블 이득이 크다.

## 구현 (모두 config 키로만 켜짐, 기존 실험 재현 유지)
- `src/data/headers.py`: 시리즈 헤더 스캔 → 지방억제(정규식+ScanOptions)·가중(T1/T2/PD)·px·좌우(태그, 없으면 영상 중심 x)
  - train 24,371 시리즈 헤더 오류 0, 좌우 판정 4,335 / 4,407 study (72개 미정 → 뒤집지 않음)
  - CSV `Anatomical_Plane`과 헤더 방향(IOP)은 24,371개 모두 일치
  - 정규식 지방억제와 CSV `Fat_Suppression`이 다른 시리즈 210개(105/105)
- `src/data/slot_image.py`: 칸 선택(`pick_slot_series`), `slot_image()`(가운데 구간 3장, 130 mm 자르기, 1–99 백분위, 뒤집기), 증강, `SlotImageDataset`
  - 칸 채움률: SAG_FLUID_FS .94, COR_FLUID_FS .96, AX_FLUID_FS .99, SAG_FLUID_NOFS .63, COR_T1 .64, SAG_T1 .43
  - 시야 중앙값 160 mm (1%: 130, 99%: 320) — 130 mm 자르기가 의미 있다
- `src/models/slot_dino.py`: `KneeSlotDino`(timm DINOv2, 마지막 n블록 + norm 학습, CLS+patch 평균) + `SlotHead`
- `src/train.py`: config `input: slot_image`, `series_meta`
- 캐시(256px) 위에서 자르므로 캐시를 다시 만들지 않는다. 130 mm는 보통 캐시 200px 안팎 → 224로 확대

## 사전 점검 (로컬 CPU)
- 실데이터 160 study, 사전학습 가중치로 40 step: loss 0.62–0.67(작은 표본이라 흔들림), logit std 0.14–0.25,
  특징의 이미지 간 std/평균 **0.61** (exp005 붕괴 모델 0.012, exp004 0.95)
- 좌·우 무릎 칸 이미지를 그려 보니 130 mm 중심 자르기와 뒤집기가 의도대로다

- 가중치는 "모델 계열별 반반"(DINO 계열 0.5, b0 계열 0.5)으로 정했다. 58개로 세밀하게 고르지 않는다.

## 결론
- 공개 레시피 재구현이 처음으로 b0를 넘었다 (단독 +0.03, 보조 CV도 +0.005). 학습은 15분이라 반복 실험이 싸다.
