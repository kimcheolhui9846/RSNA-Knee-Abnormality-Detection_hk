# exp007 — 공개 Raptor(단일 CoAtNet, LB 0.924) 방식을 우리 코드로 재구현

## 배경 (2026-10-05 조사)
- 리더보드 5,197팀: 중앙값 0.932, ≥0.943 1,400팀(공개 노트북 포크), **≥0.955 54팀**, 1위 0.963.
- 공개 0.943 파이프라인의 주력은 dreaddevelopment의 "Raptor" CoAtNet. 원작자 기록: 단일 모델 정답 58 **0.917** / LB **0.924**.
  같은 레시피의 백본 앙상블은 LB +0.001뿐, 코퍼스 확대(3,155 → 4,349 study)가 정답 58 +0.013.
- "0.946" 공개 노트북 = 공개 0.943 + 작성자 개인 ConvNeXt 10% → **성격이 다른 강한 모델을 조금 섞으면 오른다**.
- 우리 최고(exp006 앙상블) 정답 58 OOF 0.827 / LB 0.857 — Raptor와 0.09 차이. 칸 이미지 DINO를 다듬어서는 메우기 어렵다.

## 가설
공개 Raptor 학습 절차(고해상도 CNN 전체 미세조정, study당 슬라이스 44장, 소견별 attention-MIL)를 우리 코드로 재현하면
정답 58에서 0.89–0.92에 도달한다. 그 뒤 라벨·시드·백본을 바꾼 변형으로 공개 파이프라인과 성격이 다른 강한 모델을 만든다.

## 재현 대상과 우리 코드
| 항목 | 내용 |
|------|------|
| 입력 | 공개 코퍼스 `dreaddevelopment/knee-raptor-corpus`(+`-ext`): 4,407 study × 44 × 336 × 336 uint8 |
| 스택 규칙 | 칸 5개(시상 fluid 12 / 시상 non-fluid 10 / 관상 fluid 8 / 관상 6 / 축상 8), 시리즈 15–85% 구간, 2–98 백분위, 140 mm 자르기, INTER_AREA |
| 창 | 연속 3장 = RGB, 학습 무작위 12개 / 평가 고르게 24개, 384로 확대, ImageNet 정규화, 밝기 ±10% (뒤집기 없음) |
| 모델 | `coatnet_rmlp_2_rw_384.sw_in12k_ft_in1k` 전체 미세조정 + 소견별 attention-MIL (`src/models/raptor.py`) |
| 학습 | AdamW 백본 3e-5 / 헤드 1e-3, OneCycle 15%, wd 0.02, clip 3.0, bf16, bs 8, grad checkpointing, 16 epoch, 양성 가중치 (1-p)/p |
| 라벨 | 공개 Raptor와 같은 dreaddevelopment LLM soft 라벨 4,349 + 정답 58(학습 안 함, 평가만) |
| 모델 선택 | **원본과 다름**: 원본은 정답 58로 최고 epoch를 고른다 → 그 58 점수가 부푼다. 우리는 마지막 3 epoch 가중치 평균 |

### 전처리 재현 검증 (Kaggle 추론에서 같은 입력을 만들 수 있는가)
우리 `build_stack()`으로 train DICOM에서 스택을 만들어 공개 코퍼스와 비교:

| study | span 0.06–0.94 | **span 0.15–0.85** | span 0.02–0.98 |
|-------|----------------|--------------------|----------------|
| all[0], all[7], all[1500], all[3199] | 최대 차이 251–255 | **최대 차이 0, 마스크 동일** | 최대 차이 251–255 |
| extra[0], extra[600], extra[1206] | | **최대 차이 0, 마스크 동일** | |

→ 코퍼스는 15–85% 구간(v2)이다. 우리 전처리가 비트 단위로 같으므로 Kaggle test에서도 학습과 같은 입력을 만든다.

## 라벨 출처
dreaddevelopment 라벨은 우리 v2(공개 라벨 5종 평균)에 들어 있지 않다. pseudo 4,349에서 라벨별 Pearson 0.47(Synovitis)–0.92(Medial Meniscus).
→ 라벨을 바꾼 변형(v2, 두 라벨 평균)은 다양성 후보.
