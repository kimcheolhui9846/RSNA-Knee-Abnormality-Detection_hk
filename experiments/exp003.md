# exp003 — 공개 LLM 라벨(soft)로 교체

## 가설
exp002의 pseudo-label(Qwen2.5-7B, 정답 58 기준 AUC 0.803)을 공개 LLM 라벨 5종의 확률 평균(AUC 0.892)으로 바꾸면,
모델·설정이 같아도 LB가 0.834에서 오른다. 라벨 효과만 분리해서 잰다 (모델 개선은 exp004).

## 변경점 (exp002 대비)
| 항목 | exp002 | exp003 |
|------|--------|--------|
| pseudo-label | Qwen2.5-7B 추출, "언급 없음 = 음성", 0/1 | 공개 5종 **확률 평균 (soft)** |
| 라벨 파일 | `labels.csv` | `labels_v2.csv` (같은 HF 데이터셋, config `labels_file`) |
| 나머지 | — | 동일 (efficientnet_b0, 6칸×16장×256², 4 epoch, batch 2, folds_v1) |
| GPU | Secure RTX 4090 | **Community** RTX 4090 / A6000 (예산 $25 상한) |

## 라벨 근거 (정답 58 study, macro AUC)
| 출처 | AUC |
|------|-----|
| 우리 Qwen2.5-7B (exp002) | 0.803 |
| pilkwang/rsna-knee-llm-labels `report_labels_v2` | 0.870 |
| stevenleehans/rsna-knee-llm-report-labels `llm_labels_full` / `v2` / `v4_blend` | 0.878 / 0.887 / 0.893 |
| lixin73/rsna-knee-llm-report-labels-sol56 `labels_llm_gpt56sol` | 0.835 |
| **5종 확률 평균 (채택)** | **0.892** |

- 개선이 큰 라벨: Effusion 0.65→0.88, PF OA 0.70→0.90, Synovitis 0.68→0.80, ACL 0.86→0.98
- 주의: 공개 라벨 제작자도 이 58개로 라벨을 다듬었을 수 있어 58개 점수는 낙관적일 수 있다
- 라이선스: 세 데이터셋 모두 메타데이터에 라이선스 표기 없음 → 대회 안 사용은 공개 데이터 규칙상 허용,
  수상 시 공개 의무와의 관계는 확인 필요. 출처: Kaggle 사용자 pilkwang, stevenleehans, lixin73
