# exp010 — Raptor CoAtNet, 64장·구간 6–94% 코퍼스

## 배경
- 공개 원작자(dreaddevelopment) 기록: 구간을 15–85%에서 6–94%로 넓히니 Lateral Meniscus·측부인대가 좋아졌다. 공개 가중치 `raptor-knee-widedense`는 64장.
- 제3자 재현(4-arm CoAtNet) 정답 58 0.930 / LB 0.939. 공개 global96(96장) 정답 58 0.93.
- 우리 44장 모델(exp007)의 라벨별 최저는 Lateral OA 0.764, Lateral Meniscus 0.816.
- 공개 코퍼스는 44장뿐 → `src/data/build_corpus.py`(PR #25)로 train DICOM에서 직접 생성(4,407 study, 31.8 GB).

## 가설
입력만 64장·6–94%로 바꾸면 exp007(0.904) 대비 정답 58 +0.005–0.015, 특히 Lateral 라벨이 오른다.
44장 모델과 입력이 달라 앙상블 다양성도 생긴다.

## 설정
`configs/exp010_raptor64.yaml`: exp007과 같고 `corpus_dir: raptor_corpus64`, `slots: SLOTS64`, `span: [0.06, 0.94]`, seed 64. 라벨 dread.

## 결과 (2026-10-12, RunPod 4090 3.1시간, run `20261012-080329-9b09c2`)
- **정답 58 macro AUC 0.8954** (exp007 0.9037, -0.008). 가설(+0.005–0.015)과 반대.
- epoch별 정답 58은 epoch 9에 0.905로 가장 높고 이후 0.893–0.900. 최종은 마지막 3 epoch 평균(SWA).

  exp011을 뺀 3모델에 더하면 0.9125 → 0.9146.
- 앙상블에 넣으려면 추론에서 64장 스택을 44장 스택과 따로 만들어야 해 전처리 시간이 늘어난다.

## 결론
64장·6–94% 입력은 우리 설정(창 12개 학습, 창 24개 평가, 16 epoch)에서 44장보다 낫지 않다. seed 하나·58건이라 -0.008은 잡음 범위일 수 있지만,
오를 근거가 없고 추론 전처리가 늘어 **앙상블에 넣지 않고, 정제 라벨 + 64장 조합도 진행하지 않는다.** 정제 라벨(exp011, +0.012) 쪽에 집중한다.
