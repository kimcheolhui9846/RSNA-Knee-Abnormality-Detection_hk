# exp004 — DINOv2 ViT-S + 라벨별 attention + 2.5D

## 가설
공개 상위권 노트북(0.94대)이 공통으로 쓰는 세 가지 — DINOv2 백본, 소견별 attention 질의, 인접 슬라이스 3채널(2.5D) — 를
exp003(같은 라벨)에 넣으면 LB가 exp003보다 오른다. 라벨은 exp003과 같게 두어 모델 효과만 잰다.

## 변경점 (exp003 대비)
| 항목 | exp003 | exp004 |
|------|--------|--------|
| 백본 | efficientnet_b0 (흑백 1채널) | DINOv2 ViT-S/14 (`vit_small_patch14_dinov2.lvd142m`), 앞 6블록 고정, 224px |
| 입력 | 칸당 16장, 1채널 | 칸당 16장, **2.5D 3채널** (앞·현재·뒤 슬라이스) |
| 집계 | 슬라이스 평균·최대 → 칸 임베딩 → 있는 칸 평균 → 공용 출력 | 슬라이스 CLS + 칸·깊이 임베딩 → **12개 소견별 attention 질의** → 소견별 출력 |
| lr | 3e-4 (전체) | 헤드 5e-4 / 백본 3e-5, wd 0.05 |
| 라벨·fold·epoch | — | 동일 (`labels_v2.csv`, folds_v1, 4 epoch) |

참고한 공개 작업: pilkwang/rsna-knee-baseline-v1, mattiaangeli/bend-the-knee-to-dinov3-ensembled (아이디어만, 코드는 새로 작성)
