# exp005 — DINOv2 학습 부족 수정 + 라벨 대조군 exp003r

## 배경: exp004 원인 분석 (2026-10-04)
exp004(DINOv2 ViT-S + 라벨별 attention + 2.5D, labels_v2)는 CV 0.703 / LB 0.741로 exp002(0.778 / 0.834)보다 나빴다.
네 갈래로 나눠 점검했다.

| 가설 | 판정 | 근거 |
|------|------|------|
| 학습·추론 파이프라인 결함 | 아님 | 캐시 경로와 Kaggle DICOM 경로의 입력 텐서가 train 9 / test 3 study에서 비트 단위로 같음. 업로드 가중치로 추론 경로를 돌려 RunPod OOF를 오차 ≤0.0012로 재현 |
| 라벨(labels_v2) 교체 | 약함 | 정답 58 기준 라벨 품질 v2 0.892 > Qwen 0.791 (12개 중 11개 라벨에서 v2 우세). 라벨별 CV 하락폭과 라벨 품질 차이의 상관 −0.07. 남는 위험: "언급 없음"을 0.306으로 채운 칸 17%, Qwen 판단 보류(NaN 마스크)가 사라짐 |
| 모델 학습 부족 | **유력** | (1) attention 최대 가중치 0.0106 ≈ 균등 1/96 — query 초기값 0.02로 q·k가 작아 균등 평균에 머묾. (2) 백본 실효 lr 평균 ≈1.5e-5 (exp002의 1/20), 4 epoch 동안 줄일 수 있는 loss의 17–20%만 줄임. (3) OOF 예측 std 0.06–0.19로 압축, 라벨별 예측 평균이 v2 유병률과 r=0.995 |
| 노이즈 | 아님 | 정답 58 paired bootstrap: exp002 − exp004 = +0.075 [0.026, 0.127]. LB 하락 −0.093도 이 구간 안 |

코드 버그(정규화, freeze, param group, 마스크, 위치 임베딩)는 CPU에서 직접 돌려 확인했고 찾지 못했다.

## 가설
1. **exp005**: 같은 라벨(labels_v2)에서 attention 퇴화와 백본 학습 부족을 고치면 exp004보다 크게 오른다(목표: 정답 58 CV ≥ exp002 0.778).
2. **exp003r**(대조군): exp002 모델에 labels_v2만 쓰면 exp002와 비슷하거나 낫다 → 라벨은 하락 원인이 아니다.
   exp003과 학습은 같고 보조 CV만 켰다 (exp003은 Community GPU 문제로 결과 없음).

두 실행을 같은 커밋에서 Secure RTX 4090 두 대로 병렬로 돌린다.

## exp005 변경점 (exp004 대비)
| 항목 | exp004 | exp005 | 이유 |
|------|--------|--------|------|
| 질의 초기화 | std 0.02 | std 1.0 (`query_init_std`) | attention이 균등 평균에서 벗어나게 |
| 칸 풀링 경로 | 없음 | 칸별 깊이 평균·최대 → MLP → 칸 평균을 소견별 문맥에 더함 (`slot_pool`) | exp002의 최대 풀링이 국소 소견(ACL·MCL·Contusion·Fracture)에 유리 |
| 고정 블록 | 6 | 2 | MRI 도메인 적응 |
| lr (헤드 / 백본) | 5e-4 / 3e-5 | 1e-3 / 1e-4 | 학습량 부족 |
| 스케줄 | cosine | 5% 선형 warmup + cosine | 큰 lr의 초기 불안정 방지 |
| epoch | 4 | 6 | 학습량 |
| weight decay | 전 파라미터 0.05 | 1차원·임베딩·질의는 0 (`no_decay_1d`) | 임베딩·bias를 0으로 끌어당기지 않게 |
| 출력 bias | 0 | 학습 라벨 사전확률 logit (`init_bias_prior`) | exp004는 epoch 1 loss가 사전확률 수준 |
| AMP | fp16 + GradScaler | bf16 (`amp_dtype`), grad clip 1.0 | ViT 안정성 |

모든 변경은 config 키로만 켜진다. 키가 없으면 exp002–004와 같은 동작이다(재현성).

## 판단 기준
- 1차: 정답 58 OOF macro AUC (exp002 0.778). 58개로는 약 0.04보다 작은 차이를 가리지 못하므로
- 2차: 보조 CV `pseudo_holdout_auc` (fold k에서 학습에 안 쓴 pseudo study, 라벨은 labels_v2를 0.5로 이진화).
  exp003r과 exp005는 같은 라벨이라 서로 비교할 수 있다.
- exp005 ≥ exp003r이면 DINOv2 경로를 계속, 아니면 b0 경로 강화로 돌아간다.

## 예상 비용
Secure 4090 $0.74/h. exp003r 약 2–2.5h, exp005 약 4h(백본 학습 블록 6→10, epoch 4→6) → 약 $5.
