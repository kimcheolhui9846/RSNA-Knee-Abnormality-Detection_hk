# exp001 — 2D 백본 + study 단위 집계 (로드맵 1단계)

## 가설
ImageNet 사전학습 2D CNN으로 슬라이스 특징을 뽑아 칸(시리즈) → study로 집계하는 가장 단순한 구조로도
macro AUC가 무작위(0.5)보다 높다. 이후 실험의 기준선이 된다.

라벨 있는 study가 58개뿐이라(fold당 학습 약 46 / 검증 약 12) CV 분산이 매우 클 것이다.
목적은 **학습 파이프라인을 RunPod에서 끝까지 검증하고 기준 숫자를 얻는 것**이다.

## 설정 (`configs/exp001_baseline.yaml`)
| 항목 | 값 |
|------|----|
| 백본 | `efficientnet_b0` (timm, ImageNet, `in_chans=1`) |
| 입력 | 6칸(Sagittal/Coronal/Axial × 지방 억제 1/0) × 16장 × 256² |
| 집계 | 칸: 슬라이스 평균·최대 → Linear+GELU(256) + 칸 임베딩 / study: 있는 칸 평균 → Linear(12) |
| 손실 | masked BCE (라벨 있는 위치만) |
| 학습 | AdamW lr 3e-4, wd 1e-2, cosine, 15 epoch, batch 2, AMP, seed 42 |
| 증강 | 없음 (계획의 좌우 반전은 시상면에서 앞뒤 반전이 되어 이번에는 뺐다) |
| 데이터 | 라벨 있는 58 study, `folds_v1` (sha256 `82c80f07…`) |
| 실행 | RunPod RTX 4090 (runpod-hf-harness) |
